Recursos

Tudo que você precisa para dormir tranquilo

Menos ruído, mais sinal: alertas só quando importam, com contexto suficiente para agir.

🚦

Status confiável

UP, DOWN ou DEGRADED por serviço — e sem falso positivo quando o próprio Docker está inalcançável.

📈

Previsão de disco cheio

Regressão linear sobre o histórico estima quando o disco enche, com alerta amarelo e vermelho.

🖥️

VMs sob vigilância

Detecta VM parada, inacessível ou sem heartbeat, com agentes em bash e PowerShell.

⚡

Tempo real

Atualização por WebSocket: o dashboard muda no instante em que o estado muda.

🔕

Anti-spam

Cooldown de alertas persistido no banco — reinício do worker não repete notificações.

🧩

Config em runtime

O front lê a configuração ao subir, sem rebuild. Mesma imagem em qualquer ambiente.

Arquitetura

Quatro peças, um banco, zero acoplamento

O worker produz dados, o engine expõe, o dashboard exibe. Eles não se chamam por HTTP — conversam pelo PostgreSQL.
